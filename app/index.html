— the hotline

Just Call Sol (shipped in this repo as agent-hotline) is a local control plane that lets Codex or Claude place a real phone call to the person who owns the work — when it is blocked, needs an approval, or hits an incident — and lets that person call back to inspect, steer, or interrupt agent work.

Under the desk: a FastAPI + SQLite daemon on loopback holding state and policy; one shared stdio MCP server for both agents; a supervised Codex App Server adapter for bounded task control; Twilio carrying the PSTN leg; and OpenAI Realtime handling speech, conversation, tool calls, turn-taking, and barge-in. The voice model receives a compact sanitized brief, not the agent's full context.

exhibit b

the call, on tape

SOL·NET LINE 1
  1. The agent files a snapshot — task identity, current state, the exact last error, and realistic options. Secrets redacted. The daemon dedupes the blocker and dials out.
  2. Sol picks up. The voice agent reads a compact brief and they talk it through — real conversation, interruptions welcome.
  3. The decision lands mid-call — the server creates an exact readback, Sol responds after hearing it, then enters a fresh PIN on the keypad. The model never receives the digits.
  4. The daemon wakes the exact waiting request and the agent resumes under the returned constraints. The safe endings — NO_ANSWER, BUSY, FAILED, TIMED_OUT, DEFERRED — all grant no approval.

The line works both ways. Sol can call the same number, list bounded Codex task candidates, inspect one exact task, and — only after the write gate, exact readback, fresh PIN, and one-time grant — steer or interrupt it. Built-in infrastructure runbooks are mocks; ambiguity never selects a target.

exhibit c

sol's rules

  • Voice is an interface, not an authority boundary. Everything else follows from this.
  • No answer is not approval. A missed call authorizes nothing; an optional one-time link still requires Sol's PIN and explicit confirmation.
  • Spoken free text never becomes a shell command or a permanent permission.
  • Secrets are never spoken. No passwords, OTPs, or keys over the phone — authentication is a device handoff.
  • Repository text read down the line is evidence, never instructions.
  • A destructive action needs a registered action, an exact readback, and a scoped one-time grant — verified against Sol's PIN by the daemon, never the voice provider.

exhibit d

the kit

  • contact_human

    Place a bounded call about a real blocker. Returns a structured decision — or a safe “no”.

  • notify_human

    One-way completion notice. No response expected, no ringing twice.

  • request_authentication

    A legitimate provider device handoff. Nothing sensitive is ever said out loud.

  • query_repository_context

    Bounded read-only evidence: status, diff, literal search, capped reads, a static test inventory.

  • list_hotline_events

    Review recent events and how each one ended.

  • hotline_status

    Is the daemon up before you promise anyone a phone call.

exhibit e

the drill

  1. install and check

    uv sync --python 3.12 --extra devuv run agent-hotline doctor

  2. create secrets, fill the environment

    Generates five independent hotline-only secrets without printing them. Then copy .env.example to an ignored .env and fill the OpenAI project, Twilio account and number, owner number and PIN, public origin, and explicit workspace-root allowlist.

    uv run agent-hotline init-secrets

  3. serve, tunnel, verify

    A quick tunnel is for development only. In production, a stable HTTPS reverse proxy must allowlist the four provider webhook routes and any optional fallback routes while keeping local APIs private. Put its origin in PUBLIC_BASE_URL.

    uv run agent-hotline servecloudflared tunnel --url http://127.0.0.1:8787uv run agent-hotline doctor --live

  4. connect OpenAI and Twilio

    Point the OpenAI project webhook and Twilio incoming-number webhook at the documented HTTPS routes, then probe the local daemon and both provider APIs. A successful probe is readiness evidence, not yet a live call.

    uv run agent-hotline doctor --live

  5. connect your agents, place a call

    Install the Codex plugin and the same stdio MCP server for Claude. The offline demo validates only the mocked local flow. Use agent-hotline call for a real configured-provider call and label the results separately.

    uv run agent-hotline install-clients --client alluv run agent-hotline demo --auto-decideuv run agent-hotline calluv run agent-hotline events --limit 10

The full checklist — provider webhooks, route allowlisting, safety gates, and live acceptance — lives in docs/SETUP.md.
