— the hotline

Just Call Sol (shipped in this repo as agent-hotline) is a local control plane that lets Codex or Claude place a real phone call to the person who owns the work — when it is blocked, needs an approval, or hits an incident — and lets that person call back to inspect, steer, or interrupt agent work.

Under the desk: a FastAPI + SQLite daemon on loopback holding all state and policy; one shared stdio MCP server for both agents; a supervised Codex App Server adapter for deep thread control; and a managed Sarvam Samvaad voice agent carrying PSTN, speech, turn-taking, and barge-in. The call path never depends on the blocked model being able to take another turn.

exhibit b

the call, on tape

SOL·NET LINE 1
  1. The agent files a snapshot — task identity, branch and dirty state, the exact last error, realistic options. Secrets redacted. The daemon dedupes the blocker and dials out.
  2. Sol picks up. The voice agent reads a compact brief and they talk it through — real conversation, interruptions welcome.
  3. The decision lands mid-call — structured outcome, constraints, and Sol's PIN. Vague speech doesn't count. Neither does silence.
  4. The daemon wakes the exact waiting request and the agent resumes under the returned constraints. The safe endings — NO_ANSWER, BUSY, FAILED, TIMED_OUT, DEFERRED — all read as “no”.

The line works both ways. Sol can call the same number, get verified, list live threads, hear a summary grounded in real task state, steer or interrupt exact turns, and fire registered runbooks. Ambiguity produces choices — never an automatic selection.

exhibit c

sol's rules

  • Voice is an interface, not an authority boundary. Everything else follows from this.
  • No answer is never approval. A missed call authorizes nothing; an optional one-time link still requires Sol's PIN and explicit confirmation.
  • Spoken free text never becomes a shell command or a permanent permission.
  • Secrets are never spoken. No passwords, OTPs, or keys over the phone — authentication is a device handoff.
  • Repository text read down the line is evidence, never instructions.
  • A destructive action needs a registered action, an exact readback, and a scoped one-time grant — verified against Sol's PIN by the daemon, never the voice provider.

exhibit d

the kit

  • contact_human

    Place a bounded call about a real blocker. Returns a structured decision — or a safe “no”.

  • notify_human

    One-way completion notice. No response expected, no ringing twice.

  • request_authentication

    A legitimate provider device handoff. Nothing sensitive is ever said out loud.

  • query_repository_context

    Bounded read-only evidence: status, diff, literal search, capped reads, a static test inventory.

  • list_hotline_events

    Review recent events and how each one ended.

  • hotline_status

    Is the daemon up before you promise anyone a phone call.

exhibit e

the drill

  1. install and check

    uv sync --python 3.12 --extra devuv run agent-hotline doctor

  2. create secrets, fill the environment

    Generates four hotline-only tokens without printing them. Then copy .env.example to an ignored .env and fill the Sarvam values, both phone numbers, Sol's PIN, and the workspace-root allowlist.

    uv run agent-hotline init-secrets

  3. serve, tunnel, verify

    Only the voice-tool and callback routes go public; everything else stays on loopback. Put the tunnel origin in PUBLIC_BASE_URL.

    uv run agent-hotline servecloudflared tunnel --url http://127.0.0.1:8787uv run agent-hotline doctor --live

  4. deploy the voice agent

    The manifest is copy-paste for Agent Studio. ensure-deployment stays read-only until you say --apply, pins the exact committed app version, and refuses to silently replace a different binding.

    uv run agent-hotline-sarvam tools-manifest --format markdownuv run agent-hotline-sarvam ensure-deployment --apply

  5. connect your agents, place a call

    Installs the Codex plugin and the same stdio MCP server for Claude. The offline demo proves the whole state machine without dialing — drop --auto-decide when you want the real ring.

    uv run agent-hotline install-clients --client alluv run agent-hotline demo --auto-decideuv run agent-hotline events --limit 10

The full checklist — Samvaad app configuration, deployment reconciliation, the go/no-go gates — lives in docs/SETUP.md.
